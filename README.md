# 🍕 [Projeto Pizzaria Melhor Do Mundo]

Este é um projeto de site responsivo desenvolvido para uma pizzaria, focando em uma experiência do usuário agradável, cardápio visual e facilidade de navegação tanto em dispositivos desktop quanto móveis.

## 🚀 Sobre o Projeto
O objetivo deste projeto foi criar uma interface moderna e intuitiva para uma pizzaria. O site permite que os clientes visualizem o cardápio dividido por categorias (Tradicional, Vegana, Doces, Bebidas) e naveguem pelas seções da pizzaria.

O foco principal foi o **design responsivo**, garantindo que o layout se adapte perfeitamente desde telas grandes de computador até dispositivos smartphones, mantendo a legibilidade e a facilidade de uso.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização, layout (Flexbox/Grid) e design responsivo (Media Queries).
* **JavaScript:** (Se você usou, mencione aqui o que ele faz, ex: manipulação de eventos, menu hambúrguer, etc).
* **GitHub Pages:** Hospedagem do projeto.

## ✨ Funcionalidades
* **Menu de Navegação:** Acesso rápido às seções principais (Cardápio, Sobre Nós, Contatos).
* **Cardápio Categorizado:** Filtros para facilitar a busca do cliente.
* **Design Responsivo:** Layout fluido que se ajusta a qualquer tamanho de tela.
* **Cards de Produtos:** Exibição organizada de imagens, nomes, descrições e preços das pizzas.
